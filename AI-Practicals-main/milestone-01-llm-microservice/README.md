# Milestone 1 — LLM Microservice

FastAPI microservice backed by Amazon Bedrock and Amazon Nova Lite.

---

# Features

- POST /classify
- POST /summarize
- Structured JSON responses
- Pydantic validation
- Swagger docs
- Proper error handling
- Pytest test suite
- Amazon Bedrock integration using boto3

# Setup

## 1. Create Virtual Environment

```bash
python -m venv venv
```

---

## 2. Activate Environment

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Configure AWS Credentials

Create a `.env` file using `.env.example`.

Example:

```env
AWS_ACCESS_KEY_ID=your_key
AWS_SECRET_ACCESS_KEY=your_secret
AWS_SESSION_TOKEN=your_token_if_required
AWS_DEFAULT_REGION=us-east-1
```

---

# Run the Application

```bash
uvicorn main:app --reload
```

# Example Classification Request

POST `/classify`

```json
{
    "text": "This movie was fantastic."
}
```

Response:

```json
{
    "label": "positive",
    "confidence": 0.96
}
```

---

# Example Summarization Request

POST `/summarize`

```json
{
    "text": "Long article content..."
}
```

Response:

```json
{
    "summary": "Concise summary generated by Nova Lite."
}
```
